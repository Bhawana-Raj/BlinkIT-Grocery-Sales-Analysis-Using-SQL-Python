## 📌 Project Overview

This project focuses on analyzing **BlinkIT grocery sales data** to uncover valuable business insights related to:

* 📈 Sales performance
* 🛍️ Product category analysis
* 🏪 Outlet performance
* ⭐ Customer satisfaction
* 📊 Business KPI evaluation

The analysis was performed using **PostgreSQL and Python** for data cleaning, exploratory analysis, KPI calculation, and visualization.

---

# 🎯 Business Objective

The main objective of this project is to analyze BlinkIT's sales data and answer important business questions:

✅ Which product categories generate maximum revenue?
✅ How does fat content impact sales performance?
✅ Which outlets contribute more sales?
✅ How outlet characteristics affect revenue?
✅ What are customer rating patterns?

# 🗂️ Dataset Information

The dataset contains BlinkIT grocery sales information:

| Column                       | Description                   |
| ---------------------------- | ----------------------------- |
| 🆔 Item Identifier           | Unique product ID             |
| 🛒 Item Type                 | Product category              |
| 🥗 Item Fat Content          | Low Fat / Regular             |
| ⚖️ Item Weight               | Product weight                |
| 👁️ Item Visibility          | Product visibility percentage |
| 🏪 Outlet Identifier         | Unique outlet ID              |
| 📅 Outlet Establishment Year | Outlet opening year           |
| 📍 Outlet Location Type      | Outlet location category      |
| 📏 Outlet Size               | Outlet size classification    |
| 🏬 Outlet Type               | Outlet business type          |
| 💰 Sales                     | Product sales value           |
| ⭐ Rating                     | Customer rating               |
